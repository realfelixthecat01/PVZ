PVZT — учитель

Редактор задачников с тестами, выгрузкой в exe, загрузкой в облако и живой доской результатов.

  • Собирает оффлайн .pvz и самодостаточный exe
  • Загружает задачник в облако одним кликом
  • Видит прогресс каждого ученика в реальном времени
◆

PVZP — ученик

Один exe, никакого Python и Pascal устанавливать не надо. Открывает оффлайн или по токену.

  • Запускает Python и Pascal ABC через встроенные раннеры
  • Шлёт прогресс учителю, пока задачник открыт
  • Тёмная тема и подсказки, которые не бесят
☁

PVZ Cloud

Сервер, который хранит задачник ровно столько, сколько выбрал учитель. Потом автоматически удаляет.

  • Токены из 6 символов, пароль учителя проверяет сервер
  • Аккаунты, ключи активации и каталог хранятся в облаке
  • HTTPS и ограничение частоты запросов из коробки
